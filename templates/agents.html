Use the site from an AI agent

AI agents such as Claude Code can search this site, find related work and, with your permission, read and organize your tags. They connect over MCP at {{ base }}/mcp, or use the same tools as JSON at {{ base }}/api (llms.txt describes everything).
The best tool for research is rank_like: give it a few papers you know are relevant and it ranks every paper here by them, the way your tags rank new papers. Searching and ranking work without an account: 
claude mcp add --transport http resanity {{ base }}/mcp
For your own tags, reading list, recommendations and notes, the agent needs an access token. It acts as you: read-only, unless you allow changes. Anyone with the token can do what it allows, so keep it like a password and revoke it when it's no longer needed. What an agent reads goes to whoever runs the agent (for example Anthropic, for Claude).
