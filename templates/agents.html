Use Arxiv Resanity with AI agents

An AI agent such as Claude can use this site for you: search it, find related work from a few example papers, and, if you let it, read and organize your tags, reading list and notes. You ask in plain language; the agent calls the site's tools and reports back.
Its strongest tool is rank_like. Give it a few papers you know are relevant, and it ranks every paper here by them, the way your tags rank new papers. That finds work that shares no keywords with what you would have searched for. The agent can repeat it, adding good hits and steering away from off-topic ones.

Connect

claude.ai and the Claude apps. Settings → Connectors → Add custom connector, with the address

{{ base }}/mcp/me

Claude sends you to this site to log in and choose what it may do (read only, only its own agent: tags, or everything). The connection then appears under access tokens below, where you can end it any time.

Claude Code. For searching and ranking, no account is needed:

claude mcp add --transport http resanity {{ base }}/mcp

For your own tags, make an access token below and add it as a header; the page then shows the exact command.

Other agents and scripts. Any MCP client can use {{ base }}/mcp (streamable HTTP) with the header Authorization: Bearer <token>. Without MCP, the same tools are plain JSON under {{ base }}/api, and llms.txt describes them for agents. For example:

curl "{{ base }}/api/rank_like?like=2006.11239,2112.10752&days=90&limit=5&abstracts=false"

Things to ask

  • "These papers are what I'm working on: 2006.11239, 2011.13456, 2112.10752. Find the most relevant papers of the last three months and tell me what's new in them."
  • "Go through my reading list for the tag diffusion, pick the five that matter most for my project, and write a note on each saying why."
  • "Look at this week's recommendations and save the ones about video generation to a new tag video."
  • "Which papers do my saved papers in robotics cite most that I haven't saved yet?"
  • "I've read 2401.12345 and 2402.23456, mark them as read."

Good to know

  • A token acts as you. It is read-only unless you allow changes: either only to tags named agent:… (your own tags stay yours), or to everything; even then it can never delete a tag. Keep it like a password, and revoke it when you no longer need it.
  • What the agent reads (your tags, notes, the papers) goes to whoever runs it, for Claude that is Anthropic (privacy).
  • The site covers machine learning, vision, language, AI and robotics papers (cs.LG, cs.CV, cs.CL, cs.AI, cs.NE, cs.RO). With changes allowed, an agent can add any other arXiv paper by id.
  • References and "cited by" are only known for papers this site has processed: the ones its users saved.
  • Agents have rate limits like everyone; without an account, they can rank by example papers 30 times a minute.
